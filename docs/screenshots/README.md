# Screenshots für die README

Lege hier diese fünf Bilder ab. Die README verweist unter genau diesen Namen darauf:

| Datei | Seite im Panel | Tipp |
|---|---|---|
| `konsole.png` | `/konsole` | Server läuft, ein paar Spieler online, Konsole gefüllt (im Dev-Modus am einfachsten) |
| `spieler.png` | `/spieler` | Mit Online-Liste, Whitelist und Bedrock-Spieler |
| `einstellungen.png` | `/einstellungen` | Oberer Teil der Liste |
| `installation.png` | `/installation` | Mit geöffnetem Dropdown |
| `benutzer.png` | `/benutzer` | Mit zwei bis drei Benutzern |

So entstehen gute Bilder:

- Mit `npm run dev` aufnehmen: Dort gibt es Testspieler und keine echten Daten.
- Browserfenster auf etwa 1400 × 900 Pixel stellen und im dunklen Design aufnehmen.
- Vorher prüfen, dass keine echten Namen, Adressen oder Passwörter zu sehen sind.
- Als PNG speichern und möglichst unter 500 KB halten.
