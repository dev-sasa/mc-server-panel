          Discord-Benachrichtigungen

          –

          Das Panel schreibt in einen Discord-Kanal, wenn etwas passiert – zum Beispiel bei einem Absturz. Lege dafür in Discord unter Kanal bearbeiten → Integrationen → Webhooks einen Webhook an und füge die Adresse hier ein. Die Adresse wird nach dem Speichern nicht mehr angezeigt.

          Direktnachrichten (optional)

          Damit Benutzer Hinweise privat per DM bekommen können, braucht das Panel einen Discord-Bot. Im Developer Portal eine Application anlegen, unter Bot einen Token erzeugen und hier eintragen. Der Bot muss mit den Benutzern einen Server teilen (einladen über OAuth2 → URL Generator → bot), und die Benutzer müssen dort Direktnachrichten von Servermitgliedern erlauben. Der Bot braucht keine Rechte.

          Discord-Login

          –

          Benutzer können sich zusätzlich über Discord anmelden. Das klappt nur, wenn beim Benutzer (Seite „Benutzer“ oder „Mein Konto“) die passende Discord-ID hinterlegt ist.

          1. Im Discord Developer Portal eine Application anlegen.
          2. Unter OAuth2 die Redirect-URI eintragen:
          3. Client-ID und Client-Secret hier eintragen, den Login aktivieren und mit dem Knopf unten in dieser Karte speichern.

          Die eigene Discord-ID findest du mit aktiviertem Entwicklermodus per Rechtsklick auf dein Profil → „Benutzer-ID kopieren“. Oder du versuchst den Login einmal: dann wird dir die ID angezeigt.

            Der gesamte Server-Ordner wird durch dieses Backup ersetzt. Der aktuelle Stand bleibt als „.before-restore“ erhalten. Der Server muss gestoppt sein.
